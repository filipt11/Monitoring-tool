main module

Background polling loop for Cisco and Juniper network devices.

Reads the device inventory from PostgreSQL (populated via poller.api), polls each device asynchronously, and writes CPU, memory, availability, and interface metrics to InfluxDB. Concurrency is limited by semaphore to MAX_DEVICES devices in parallel.

Configuration:

Polling interval is POLLING_INERVAL seconds (default 300). InfluxDB bucket and organisation come from poller.config.

async poller.main.poll_single_device(device: Device, client: httpx.AsyncClient) → None[source]

Poll one device and persist metrics to InfluxDB.

Dispatches to poll_juniper_device_async() or poll_cisco_device_async() based on device.vendor. When CPU and memory are unavailable, only a status=0 (down) point is written.

Parameters:

  • device – Device row with connection credentials and metadata.

  • client – Shared httpx.AsyncClient for HTTP requests.

Note

Acquires semaphore for the duration of the poll. Errors are logged and swallowed so other devices continue polling.

async poller.main.poll_devices_main() → None[source]

Poll every known device once and write results to InfluxDB.

Refreshes cached_device_list from PostgreSQL when possible; on connection failure, reuses the previously cached list and logs a warning. All devices are polled concurrently via asyncio.gather().

Note

Creates a dedicated httpx.AsyncClient per cycle with verify=False.

poller.main.save_polled_device_data(device: DeviceWithPolledData, status: int) → None[source]

Write a single device metrics point to InfluxDB.

Parameters:

  • device – Polled CPU and memory values together with identity tags.

  • status – 1 when the device responded with metrics; 0 when only availability (down) should be recorded.

Note

Writes to measurement device_statistics in INFLUX_BUCKET. Metric fields are omitted when status is 0.

poller.main.save_polled_interface_data(device_id: int, device_hostname: str, device_ip: str, interfaces_raw: list) → None[source]

Write interface counter and utilization points to InfluxDB.

Parameters:

  • device_id – Primary key of the polled device.

  • device_hostname – Hostname tag for InfluxDB series.

  • device_ip – Management IP tag for InfluxDB series.

  • interfaces_raw – List of interface dicts from vendor polling (see InterfaceData).

Note

Writes to measurement interface_statistics. Utilization fields (in_bps, out_bps, in_util_pct, out_util_pct) are computed via calculate_utilization() when a previous sample exists in last_polls. Admin-down interfaces store status fields only.

poller.main.calculate_utilization(hostname: str, if_name: str, direction: str, current_octets: int, speed_bps: int) → tuple[float | None, float | None][source]

Compute link bitrate and utilization from SNMP-style octet counters.

Compares current_octets against the previous sample stored in last_polls for the same hostname, if_name, and direction ("in" or "out").

Parameters:

  • hostname – Device hostname used as part of the cache key.

  • if_name – Interface name used as part of the cache key.

  • direction – Traffic direction, "in" or "out".

  • current_octets – Latest cumulative octet counter from the device.

  • speed_bps – Interface speed in bits per second for utilization %.

Returns:

(bps, util_pct) when a valid delta exists; (None, None) on the first sample, non-positive time delta, or counter reset.

async poller.main.main() → None[source]

Initialize the database and run the polling loop indefinitely.

Calls init_db(), seeds example devices via seed_devices(), then repeatedly invokes poll_devices_main() separated by POLLING_INERVAL seconds.

Note

Returns early (without polling) when PostgreSQL initialization fails.
