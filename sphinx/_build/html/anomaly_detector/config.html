config module

Runtime configuration for the anomaly detector service.

Values are read from environment variables when present, with sensible defaults for local development (InfluxDB on localhost, API on port 8010).

anomaly_detector.config.API_PORT = 8010

TCP port for the FastAPI anomaly detector HTTP server.

anomaly_detector.config.INFLUX_URL = 'http://localhost:8086'

Base URL of the InfluxDB instance that stores polled metrics.

anomaly_detector.config.INFLUX_TOKEN = 'secret_token'

Authentication token for InfluxDB queries.

anomaly_detector.config.INFLUX_ORG = 'my_org'

InfluxDB organization name.

anomaly_detector.config.INFLUX_BUCKET = 'network_metrics'

Bucket that holds device_statistics / interface_statistics measurements.

anomaly_detector.config.POLLING_INTERVAL_SEC = 300

Expected poll interval in seconds; used to merge nearby CUSUM flags into episodes.

anomaly_detector.config.DEFAULT_LOOKBACK_HOURS = 12

Default [start, end] window length (hours) when the client omits both parameters.

anomaly_detector.config.CONTEXT_LOOKBACK_HOURS = 12

Minimum computation window (hours) so EWMA/CUSUM have enough history before filtering.
