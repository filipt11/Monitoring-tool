main module

FastAPI application simulating Cisco IOS XE or Juniper network devices.

The simulator exposes vendor-specific HTTP endpoints that return realistic RESTCONF (Cisco) or RPC-style (Juniper) JSON payloads. Device behaviour (CPU, memory, interface counters) is driven by a BaseDevice subclass selected at startup from environment variables.

Environment Variables:
DEVICE_PROFILE (str): Utilization preset. Accepted values are

high_utilized, low_utilized, average_utilized, or custom. Any other value (including the default standard) falls back to AverageUtilizedCiscoDevice.

DEVICE_IP (str): Simulated device IP address. Default: 0.0.0.0. DEVICE_HOSTNAME (str): Simulated hostname. Default: s-cat-def-1. DEVICE_VENDOR (str): Device vendor, cisco or juniper. Default:

cisco.

DEVICE_MODEL (str): Hardware model string returned in inventory/system

responses. Default: Catalyst 9000.

DEVICE_USERNAME (str): HTTP Basic auth username. Default: admin. DEVICE_PASSWORD (str): HTTP Basic auth password. Default: 123. DEVICE_PORT (int): Uvicorn listen port. Default: 443. DEVICE_IS_HTTPS (str): Whether the simulated device uses HTTPS

(informational only). Truthy values: true, 1, yes. Default: false.

When DEVICE_PROFILE=custom, the following optional variables override fields on CustomProfile:

DEVICE_MEAN, DEVICE_DEVIATION, DEVICE_MIN_VAL, DEVICE_MAX_VAL, DEVICE_SPIKE_CHANCE, DEVICE_SPIKE_MIN, DEVICE_SPIKE_MAX, DEVICE_SPIKE_MEAN, DEVICE_SPIKE_DEVIATION, DEVICE_DROP_CHANCE, DEVICE_DROP_MIN, DEVICE_DROP_MAX, DEVICE_DROP_MEAN, DEVICE_DROP_DEVIATION.

simulator.main.authenticate(credentials: fastapi.security.HTTPBasicCredentials = fastapi.Depends) → str[source]

Validate HTTP Basic credentials for all simulator endpoints.

Parameters:

credentials – Username and password extracted from the Authorization: Basic header by FastAPI’s dependency injection.

Returns:

The authenticated username when credentials match USERNAME and PASSWORD.

Raises:

fastapi.HTTPException – With status code 401 Unauthorized when the username or password does not match. The response includes a WWW-Authenticate: Basic header.

async simulator.main.cpu_usage()

Return simulated five-second CPU utilization (Cisco RESTCONF).

Returns:

RESTCONF payload keyed by

Cisco-IOS-XE-process-cpu-oper:five-seconds. The value is an integer percentage in the range 0–100, produced by get_cpu().

Return type:

dict

Note

Requires HTTP Basic authentication.

async simulator.main.memory_usage()

Return simulated processor memory statistics (Cisco RESTCONF).

Returns:

RESTCONF payload under

Cisco-IOS-XE-memory-oper:memory-statistics containing a memory-statistic list. The Processor entry reflects live values from get_total_memory() and get_used_memory(); other entries are static placeholders.

Return type:

dict

Note

Requires HTTP Basic authentication.

async simulator.main.get_model()

Return simulated device hardware inventory (Cisco RESTCONF).

Returns:

RESTCONF payload under

Cisco-IOS-XE-device-hardware-oper:device-inventory. The list contains chassis, DRAM, and CPU entries. hw-description fields for chassis entries use model.

Return type:

dict

Note

Requires HTTP Basic authentication.

async simulator.main.get_hostname()

Return type:

dict

Note

Requires HTTP Basic authentication.

async simulator.main.get_interfaces_state()

Return simulated interface state and traffic counters (Cisco RESTCONF).

Returns:

RESTCONF payload under ietf-interfaces:interfaces-state

with an interface list. Each interface includes admin/oper status, speed, MAC address, and statistics with in-octets / out-octets counters from get_interfaces().

Return type:

dict

Note

Requires HTTP Basic authentication. Timestamp fields (last-change, discontinuity-time) are static placeholders.

async simulator.main.get_interface_information()

Return simulated Juniper interface information (RPC).

Returns:

Juniper RPC-style payload with key interface-information

containing a physical-interface list. Each entry mirrors Juniper’s get-interface-information output, including logical sub-interfaces with byte counters sourced from get_interfaces().

Return type:

dict

Note

Requires HTTP Basic authentication. Most fields outside counters and status are static placeholders.

async simulator.main.get_route_engine_information()

Return simulated Juniper route-engine CPU and memory statistics (RPC).

Returns:

Juniper RPC-style payload under route-engine-information.

cpu-idle is derived as 100 - get_cpu(); memory fields use get_total_memory() and get_used_memory().

Return type:

dict

Note

Requires HTTP Basic authentication. Load averages and secondary CPU fields are static placeholders.

async simulator.main.get_system_information()

Return simulated Juniper system information (RPC).

Returns:

Juniper RPC-style payload under system-information with

host-name from hostname and hardware-model from model. OS version and serial number are static placeholders.

Return type:

dict

Note

Requires HTTP Basic authentication.

simulator.main.main() → None[source]

Start the simulator FastAPI server with Uvicorn.

Binds to 0.0.0.0 on PORT. Vendor-specific routes are already registered on app at import time based on VENDOR.

Raises:

OSError – If the configured port is already in use or cannot be bound.
