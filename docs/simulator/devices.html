devices module

Simulated network device models for Cisco and Juniper vendors.

Each concrete class represents a device with a specific utilization profile (high, low, average, or custom). Devices expose BaseDevice.get_cpu(), BaseDevice.get_used_memory(), BaseDevice.get_total_memory(), and BaseDevice.get_interfaces() which the FastAPI layer in simulator.main calls to build vendor-specific API responses.

Interface counters are stateful: each call to BaseDevice.get_interfaces() advances in-octets and out-octets based on interface speed and admin status.

Abstract base model for a simulated network device.

Stores connection metadata and maintains rolling interface byte counters. Subclasses override metric methods and populate interfaces_list with vendor-specific interface definitions.

Return the current simulated used memory in bytes.

Returns:

Number of bytes currently in use. The base implementation delegates to simulator.logic.get_average_utilized_ram() using get_total_memory() as the capacity.

get_total_memory() → int[source]

Return the total installed memory in bytes.

Returns:

Total memory capacity in bytes. Default is 762551372 (~728 MB). Subclasses may override to simulate different hardware.

get_interfaces() → list[dict[str, Any]][source]

Return interface definitions with updated traffic counters.

For each interface in interfaces_list, increments in-octets and out-octets when admin-status is up and speed is greater than zero. Interfaces with if-index in range(20, 31) use higher utilization growth rates.

Returns:

  • name (str): Interface name.

  • type (str): IANA or vendor interface type.

  • admin-status (str): up or down.

  • oper-status (str): Mirrors admin-status.

  • if-index (int): SNMP interface index.

  • phys-address (str): MAC address.

  • speed (str): Link speed in bits per second.

  • in-octets (str): Cumulative inbound byte counter.

  • out-octets (str): Cumulative outbound byte counter.

Return type:

List of interface dicts, each containing

Note

Counters are persisted in interface_counters between calls.

class simulator.devices.BaseCiscoDevice(ip_address: str, vendor: str, hostname: str, model: str, username: str, password: str, port: int, https: bool)[source]

Bases: BaseDevice

Base Cisco device simulating RESTCONF-compatible IOS XE responses.

Populates interfaces_list with a default set of Cisco interfaces (VLAN, GigabitEthernet, Loopback). CPU and memory methods inherit average utilization behaviour from BaseDevice.

See also

simulator.main for the RESTCONF endpoints that consume this device’s metrics.
