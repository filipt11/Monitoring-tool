cisco_polling module

Cisco IOS XE RESTCONF polling and response parsing.

Contacts three RESTCONF endpoints in parallel (CPU, memory, interfaces), parses YANG JSON payloads, and returns a normalized PollingResult consumed by poller.main and poller.api (device modeling).

RESTCONF paths polled:

  • /restconf/data/Cisco-IOS-XE-process-cpu-oper:cpu-usage/cpu-utilization/five-seconds

  • /restconf/data/Cisco-IOS-XE-memory-oper:memory-statistics

  • /restconf/data/ietf-interfaces:interfaces-state

async poller.cisco_polling.poll_cisco_device_async(device: Device, client: httpx.AsyncClient) → PollingResult[source]

Poll a Cisco device and return normalized metrics.

Fetches CPU, memory, and interface RESTCONF data concurrently. Each request is isolated — a failure in one endpoint does not block parsing of the others. Device status is "up" when at least one metric category returns data.

Parameters:

  • device – Device row with connection credentials and https flag.

  • client – Shared httpx.AsyncClient from the polling loop.

Returns:

PollingResult with cpu, memory fields, and a list of admin-up InterfaceData entries.

Extract five-second CPU utilization from a RESTCONF CPU response.

Parameters:

raw_cpu – JSON payload from the Cisco CPU RESTCONF endpoint.

Returns:

CPU usage as an integer percentage (0–100).

Raises:

  • ValueError – When the value cannot be converted to int.

poller.cisco_polling.parse_interfaces(raw_interfaces: dict[str, Any]) → list[InterfaceData][source]

Parse admin-up interfaces with traffic counters for metric polling.

Parameters:

raw_interfaces – JSON payload from the ietf-interfaces:interfaces-state RESTCONF endpoint.

Returns:

List of InterfaceData for interfaces with admin-status equal to "up".

Raises:

ValueError – When no qualifying interfaces are found.

poller.cisco_polling.parse_interfaces_catalog(raw_interfaces: dict[str, Any]) → list[InterfaceData][source]

Parse all interface entries for inventory discovery.

Unlike parse_interfaces(), includes administratively down interfaces and does not require non-empty statistics. Used by poller.interface_discovery when syncing the PostgreSQL interface catalog.

Parameters:

raw_interfaces – JSON payload from the ietf-interfaces:interfaces-state RESTCONF endpoint.

Returns:

List of InterfaceData for every interface in the response (may be empty).
