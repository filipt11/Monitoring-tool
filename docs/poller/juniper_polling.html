juniper_polling module

Juniper Junos RPC polling and response parsing.

Contacts route-engine and interface RPC endpoints in parallel, parses Junos JSON payloads, and returns a normalized PollingResult consumed by poller.main and poller.api (device modeling).

RPC paths polled:

  • POST /rpc/get-route-engine-information — CPU and memory

  • POST /rpc/get-interface-information — interface counters

async poller.juniper_polling.poll_juniper_device_async(device: Device, client: httpx.AsyncClient) → PollingResult[source]

Poll a Juniper device and return normalized metrics.

Fetches route-engine and interface RPC data concurrently. CPU is derived as 100 - cpu-idle. Device status is "up" when at least one metric category returns data.

Parameters:

  • device – Device row with connection credentials and https flag.

  • client – Shared httpx.AsyncClient from the polling loop.

Returns:

PollingResult with cpu, memory fields, and admin-up InterfaceData entries.

poller.juniper_polling.parse_cpu(raw_route_engine: dict[str, Any]) → int[source]

Extract CPU utilization from Junos route-engine information.

Parameters:

raw_route_engine – JSON payload from /rpc/get-route-engine-information.

Returns:

CPU usage as 100 - cpu-idle (integer percentage).

Raises:

  • KeyError – When expected nested keys are missing.

  • ValueError – When cpu-idle cannot be converted to int.

poller.juniper_polling.parse_memory(raw_route_engine: dict[str, Any]) → tuple[int, int, float][source]

Extract memory metrics from Junos route-engine information.

Parameters:

raw_route_engine – JSON payload from /rpc/get-route-engine-information.

Returns:

(total_memory, used_memory, memory_pct) where total_memory and used_memory are in bytes and memory_pct is the buffer utilization percentage reported by Junos.

Note

Total memory is parsed from memory-installed-size (MB in parentheses) and converted to bytes. When parsing fails, total_memory defaults to 0 and a warning is logged.

poller.juniper_polling.parse_interfaces(raw_interfaces: dict[str, Any]) → list[InterfaceData][source]

Parse admin-up physical interfaces with byte counters for polling.

Parameters:

raw_interfaces – JSON payload from /rpc/get-interface-information.

Returns:

List of InterfaceData for physical interfaces with admin-status equal to "up". Byte counters are read from the first logical sub-interface’s traffic-statistics.

Raises:

ValueError – When no qualifying interfaces are found.

poller.juniper_polling.parse_interfaces_catalog(raw_interfaces: dict[str, Any]) → list[InterfaceData][source]

Parse all physical interfaces for inventory discovery.

Unlike parse_interfaces(), includes administratively down interfaces. Used by poller.interface_discovery when syncing the PostgreSQL interface catalog.

Parameters:

raw_interfaces – JSON payload from /rpc/get-interface-information.

Returns:

List of InterfaceData for every physical interface in the response (may be empty).
